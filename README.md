An entry for the [make.fun bounty "The 3AM Fridge Text"](https://make.fun/bounty/u-deysumbrella-the-3am-fridge-text-4c3e721d): the one line a smart fridge would text its owner at 3am.

## The line

> 3am. I saw you eat the last slice standing up in the dark over the sink. No judgment. Well. Some judgment.

The fridge has been awake all night, humming in the dark, and it has seen things. Tonight it finally decided to speak — not about milk, ice, or a door left open, but about the last slice, eaten standing up, in the dark, over the sink. No judgment. Well. Some judgment.

## Run

```sh
python3 main.py
```

Writes exactly one line to `$MAKEFUN_OUTPUT_DIR/entry.txt` (or `/output/entry.txt` when the variable is unset). Python 3.13, standard library only, deterministic: identical bytes on every run.
